# Security Policy

## Supported Versions

We support security fixes for the latest version on the default branch.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately by emailing:

- `security@quorum.local` (replace with a real address before publishing)

Include:

- A clear description of the issue and impact
- Reproduction steps or a proof of concept
- Affected versions/commit SHA (if known)
- Any relevant logs or screenshots

We will acknowledge receipt within a few business days and coordinate a fix and
responsible disclosure timeline.
